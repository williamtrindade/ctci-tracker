# 16.2 Word Frequencies — Frequência de Palavras

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 16, questão/question **16.2**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Exercício (a versão "várias consultas"):** implemente `Solution.WordFrequencies`:
`new WordFrequencies(String[] book)` pré-processa as palavras (ignorando maiúsculas/minúsculas e espaços ao redor) e
`int getFrequency(String word)` responde em O(1). Retorne `-1` para `word` nula ou vazia e `0` se não aparecer.
