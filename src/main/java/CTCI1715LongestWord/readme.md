# 17.15 Longest Word — Maior Palavra

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 17, questão/question **17.15**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `String printLongestWord(String[] arr)` — a palavra deve ser formada por **duas ou mais** outras palavras
da lista (uma mesma palavra pode ser repetida, ex.: `"catcat"`). Empate: qualquer uma. Nenhuma → `""`.
