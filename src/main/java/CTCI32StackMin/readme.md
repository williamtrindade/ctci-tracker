# 3.2 Stack Min — Pilha com Mínimo

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 3, questão/question **3.2**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Exercício:** implemente `Solution.StackWithMin` com `push(int)`, `int pop()`, `int peek()`, `int min()` e
`boolean isEmpty()`. `pop`, `peek` e `min` em pilha vazia lançam `java.util.EmptyStackException`.
