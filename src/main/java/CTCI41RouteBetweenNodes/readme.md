# 4.1 Route Between Nodes — Rota entre Nós

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 4, questão/question **4.1**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `boolean routeExists(Map<Integer, List<Integer>> graph, int start, int end)` — o grafo é uma lista
de adjacência (nó → vizinhos para onde há aresta). Nós podem não aparecer como chave (sem arestas de saída).
`start == end` conta como rota.
