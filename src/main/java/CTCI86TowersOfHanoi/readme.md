**Exercício:** a classe `Tower` (pronta) é uma pilha que **lança exceção** se um disco maior for colocado sobre um menor
e conta os movimentos. Implemente `void moveDisks(int n, Tower origin, Tower destination, Tower buffer)` usando apenas
`tower.moveTopTo(otherTower)`.
