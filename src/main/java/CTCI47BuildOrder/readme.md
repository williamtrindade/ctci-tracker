# 4.7 Build Order — Ordem de Build

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 4, questão/question **4.7**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `List<String> findBuildOrder(String[] projects, String[][] dependencies)` — cada dependência é
`{primeiro, segundo}` (o segundo depende do primeiro). Retorne **qualquer** ordem válida com todos os projetos, ou
`null` se houver ciclo.
