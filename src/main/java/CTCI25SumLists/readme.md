# 2.5 Sum Lists — Somar Listas

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 2, questão/question **2.5**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `ListNode addLists(ListNode l1, ListNode l2)` (ordem reversa) e
`ListNode addListsForward(ListNode l1, ListNode l2)` (follow up, ordem direta). Listas vazias (`null`) valem 0;
se as duas forem `null`, retorne `null`. Não use conversão para `int`/`long` (os números podem ser enormes).
