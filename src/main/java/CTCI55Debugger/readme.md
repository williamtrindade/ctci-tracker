# 5.5 Debugger — Depurador

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 5, questão/question **5.5**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Exercício:** depois de entender a expressão, implemente:

* `boolean expression(int n)` — exatamente o que a expressão do livro calcula;
* `boolean isPowerOfTwo(int n)` — usa a mesma ideia, mas retorna `true` **somente** para potências de 2 (1, 2, 4, …).
  Atenção ao caso que a expressão original trata "errado".
