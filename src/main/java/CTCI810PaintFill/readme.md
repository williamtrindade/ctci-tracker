# 8.10 Paint Fill — Balde de Tinta

> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `boolean paintFill(int[][] screen, int r, int c, int newColor)` — vizinhança de 4 direções (cima,
baixo, esquerda, direita). Retorne `false` (sem alterar nada) se o ponto já tiver a nova cor; senão pinte e retorne
