# 6.10 Poison — Veneno

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 6, questão/question **6.10**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Exercício:** implemente `int findPoisonedBottle(PoisonLab lab)`. O `PoisonLab` (pronto) tem:
`getBottleCount()`, `getStripCount()`, `addDrop(int bottle, int strip)`, `List<Integer> runTestsAndWait()` (roda os
testes, avança **7 dias** e retorna as tiras positivas) e `getDaysElapsed()`. Os testes exigem a resposta em **7 dias**.
