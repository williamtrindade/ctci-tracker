# 16.9 Operations — Operações

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 16, questão/question **16.9**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `int subtract(int a, int b)`, `int multiply(int a, int b)`, `int divide(int a, int b)` — sem usar `-`
(binário ou unário), `*`, `/` ou `%`. A divisão trunca em direção a zero (como em Java); divisão por zero lança
`ArithmeticException`. Os testes usam valores até ±10.000.
