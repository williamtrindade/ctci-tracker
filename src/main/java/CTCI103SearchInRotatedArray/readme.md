# 10.3 Search in Rotated Array — Busca em Array Rotacionado

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 10, questão/question **10.3**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `int search(int[] a, int x)` — retorne **um** índice de `x` ou `-1`. O array **pode ter duplicatas**
(ex.: `{2, 2, 2, 3, 4, 2}`), como discutido no livro.
