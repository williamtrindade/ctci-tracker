# 11.1 Mistake — Erro

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 11, questão/question **11.1**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Exercício:** implemente a versão **corrigida** em Java:

* `List<String> countdown()` — as linhas que o programa deveria imprimir (`"100"`, `"99"`, …, `"0"`);
* `String correctFormatSpecifier()` — o especificador de `printf` correto para `unsigned int`;
* `long buggyLoopIterations(long limit)` — simule o laço original com aritmética de `unsigned int` (32 bits) e retorne
  quantas iterações ele executa até `limit` (o laço original nunca termina, então o resultado deve ser `limit`).
