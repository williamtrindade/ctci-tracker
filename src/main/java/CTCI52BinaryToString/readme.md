# 5.2 Binary to String — Binário para String

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 5, questão/question **5.2**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Formato (como no livro):** retorne a string começando com `"."` seguida dos bits, ex.: `0.625 -> ".101"`. O
limite de 32 caracteres **inclui** o ponto. Números fora de `(0, 1)` também retornam `"ERROR"`.

**Assinatura:** `String printBinary(double num)`
