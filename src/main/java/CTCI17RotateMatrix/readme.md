# 1.7 Rotate Matrix — Rotacionar Matriz

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 1, questão/question **1.7**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Regras (como no livro):** rotação de 90° no sentido **horário**, in place. Retorne `false` (sem alterar nada) se a
matriz for vazia ou não for quadrada; caso contrário rotacione e retorne `true`.

**Assinatura:** `boolean rotate(int[][] matrix)`
