# 17.11 Word Distance — Distância entre Palavras

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 17, questão/question **17.11**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Exercício:**

* `int findClosest(String[] words, String word1, String word2)` — uma passada só; distância = diferença de índices;
  `-1` se alguma palavra não aparecer;
* `Solution.WordDistanceIndex(String[] words)` com `int distance(String word1, String word2)` — para consultas
  repetidas (pré-processe as posições de cada palavra).
