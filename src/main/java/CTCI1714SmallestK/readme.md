# 17.14 Smallest K — Os K Menores

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 17, questão/question **17.14**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `int[] smallestK(int[] array, int k)` — qualquer ordem; não altere o array original. `k` entre 0 e
`array.length`. Tente fazer melhor que O(n log n) (max-heap ou seleção).
