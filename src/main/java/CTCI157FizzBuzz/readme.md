# 15.7 FizzBuzz

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 15, questão/question **15.7**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Exercício:** implemente `Solution.FizzBuzz(int n, Consumer<String> printer)` e `void run()`: crie as 4 threads, espere
todas terminarem. Cada saída deve ser enviada a `printer` **pela thread responsável** (os testes verificam a ordem e quais
threads imprimiram cada tipo).
