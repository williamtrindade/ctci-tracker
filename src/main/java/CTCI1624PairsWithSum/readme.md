# 16.24 Pairs with Sum — Pares com Soma

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 16, questão/question **16.24**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Regras:** cada **elemento** (posição) do array pode ser usado em no máximo um par, e você deve formar o **máximo** de
pares possível. Retorne cada par como `{menor, maior}`; a ordem dos pares não importa.

**Assinatura:** `List<int[]> printPairSums(int[] array, int sum)` — O(n).
