# 3.4 Queue via Stacks — Fila com Pilhas

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 3, questão/question **3.4**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Exercício:** implemente `Solution.MyQueue<T>` usando **apenas duas `java.util.Stack`**: `add(T)`, `T remove()`,
`T peek()`, `int size()`, `boolean isEmpty()`. `remove`/`peek` em fila vazia lançam
`java.util.NoSuchElementException`.
