# 16.3 Intersection — Interseção

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 16, questão/question **16.3**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `Point intersection(Point start1, Point end1, Point start2, Point end2)` — `Point` já existe. Retorne
`null` se não se intersectam. Se os segmentos forem colineares e se sobrepuserem, retorne **qualquer** ponto da
sobreposição. Trate retas verticais.
