# 5.4 Next Number — Próximo Número

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 5, questão/question **5.4**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `int getNext(int n)` (menor número **maior** que `n` com a mesma quantidade de 1s) e
`int getPrev(int n)` (maior número **menor** que `n` com a mesma quantidade de 1s). Ambos consideram apenas inteiros
positivos e retornam `-1` se não existir resposta.
