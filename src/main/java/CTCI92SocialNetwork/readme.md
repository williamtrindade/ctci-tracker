# 9.2 Social Network — Rede Social

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 9, questão/question **9.2**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Exercício:** implemente `List<Integer> findPathBiBFS(Map<Integer, List<Integer>> friends, int source, int
destination)` usando **BFS bidirecional** (a partir da origem e do destino ao mesmo tempo). A amizade é simétrica.
Retorne o menor caminho (lista de ids, da origem ao destino, inclusive) ou `null` se não existir.
