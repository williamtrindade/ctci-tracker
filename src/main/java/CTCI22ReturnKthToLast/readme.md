# 2.2 Return Kth to Last — K-ésimo a partir do Fim

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 2, questão/question **2.2**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Regras (como no livro):** `k = 1` retorna o último nó, `k = 2` o penúltimo etc. Retorne `null` se `k` for menor
que 1 ou maior que o tamanho da lista.

**Assinatura:** `ListNode kthToLast(ListNode head, int k)`
