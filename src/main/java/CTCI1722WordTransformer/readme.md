# 17.22 Word Transformer — Transformador de Palavras

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 17, questão/question **17.22**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `List<String> transform(String start, String stop, Set<String> words)` — retorne o caminho **mais curto**
(de `start` a `stop`, inclusive) ou uma lista vazia se não existir. `start == stop` → `[start]`.
