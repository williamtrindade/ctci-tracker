# 16.8 English Int — Inteiro por Extenso em Inglês

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 16, questão/question **16.8**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Formato (como o código do livro):** palavras separadas por **um espaço**, sem vírgulas e sem hífen:
`1234 -> "One Thousand Two Hundred Thirty Four"`, `0 -> "Zero"`, `-12 -> "Negative Twelve"`,
`1000010 -> "One Million Ten"`. Precisa funcionar para `Integer.MIN_VALUE`.

**Assinatura:** `String convert(int num)`
