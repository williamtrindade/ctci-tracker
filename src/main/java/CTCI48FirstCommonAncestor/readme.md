# 4.8 First Common Ancestor — Primeiro Ancestral Comum

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 4, questão/question **4.8**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `TreeNode commonAncestor(TreeNode root, TreeNode p, TreeNode q)` — retorne `null` se `p` ou `q` não
estiver na árvore. Se um nó for ancestral do outro, ele é a resposta (um nó é ancestral de si mesmo). **Não use o
campo `parent`** (é a versão sem links para o pai do livro).
