# 10.1 Sorted Merge — Merge Ordenado

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 10, questão/question **10.1**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `void merge(int[] a, int[] b, int countA, int countB)` — `countA` e `countB` são as quantidades de
elementos válidos; `a.length >= countA + countB`. Não use array auxiliar.
