# 17.1 Add Without Plus — Somar sem o +

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 17, questão/question **17.1**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `int add(int a, int b)` — apenas operadores de bits. Deve se comportar como `a + b` do Java (inclusive
negativos e overflow).
