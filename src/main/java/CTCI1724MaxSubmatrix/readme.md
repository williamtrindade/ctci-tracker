# 17.24 Max Submatrix — Submatriz Máxima

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 17, questão/question **17.24**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `SubMatrix getMaxMatrix(int[][] matrix)` — `SubMatrix(rowStart, colStart, rowEnd, colEnd, sum)` já existe
(índices inclusivos). A submatriz deve ter **pelo menos uma célula** (se tudo for negativo, retorne o maior elemento).
Tente O(N³). Matriz vazia → `null`.
