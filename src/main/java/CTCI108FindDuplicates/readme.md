# 10.8 Find Duplicates — Encontrar Duplicatas

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 10, questão/question **10.8**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `List<Integer> checkDuplicates(int[] array)` — "imprimir" = adicionar na lista, **na ordem em que cada
repetição aparece** (como o código do livro: um número que aparece 3 vezes é reportado 2 vezes). Use um vetor de bits
de 32.000 bits (4 KB).
