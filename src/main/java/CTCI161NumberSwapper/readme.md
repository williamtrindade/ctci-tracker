# 16.1 Number Swapper — Trocar Números

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 16, questão/question **16.1**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `int[] swap(int a, int b)` — sem variável temporária, troque `a` e `b` (com diferença/soma ou XOR) e
retorne `{a, b}` já trocados. Deve funcionar com overflow (ex.: `Integer.MAX_VALUE` e `-1`).
