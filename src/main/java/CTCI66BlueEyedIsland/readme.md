# 6.6 Blue-Eyed Island — Ilha dos Olhos Azuis

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 6, questão/question **6.6**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Exercício:**

* `int daysToLeave(int blueEyedPeople)` — a resposta fechada (lança `IllegalArgumentException` se `< 1`);
* `int simulate(boolean[] isBlueEyed)` — simule noite a noite o raciocínio de cada pessoa (cada uma só usa o que vê e
  quem já foi embora) e retorne em qual noite os olhos azuis partem.
