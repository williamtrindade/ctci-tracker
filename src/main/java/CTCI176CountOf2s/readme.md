# 17.6 Count of 2s — Contagem de 2s

> 📖 **Enunciado / Prompt:** *Cracking the Coding Interview*, 6th ed. — Capítulo/Chapter 17, questão/question **17.6**.
> Leia o enunciado no livro antes de começar. / Read the prompt in the book first.

**Assinatura:** `int numberOf2sInRange(int n)` — conte os dígitos "2" em todos os números de 0 a n (inclusive). Deve ser
rápido para n grande (não percorra todos os números).
